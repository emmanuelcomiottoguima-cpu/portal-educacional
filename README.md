
# ⚡ BermanuelVolts

### Portal Educacional de Eletroeletrônica

O BermanuelVolts é um portal educacional desenvolvido
para facilitar o estudo de conceitos fundamentais
de Eletroeletrônica.

O projeto apresenta uma biblioteca com 20 assuntos,
organizados em cinco categorias, permitindo que
os estudantes naveguem pelos conteúdos de diferentes
grupos.

## Integrantes

- Bernardo Panitz
- Emmanuel Comiotto Guimarães

**Grupo:** 04

**Tema:** 5.4 — Relés e Chaves Eletromecânicas

## Objetivo

Desenvolver um portal educacional com explicações
técnicas, exemplos práticos, recursos visuais,
resumos e atividades interativas.

Nosso conteúdo aborda o funcionamento dos relés
e das chaves eletromecânicas, suas principais
características e aplicações.

## Tecnologias utilizadas

- HTML5 — estrutura das páginas
- CSS3 — identidade visual e responsividade
- JavaScript — pesquisa, navegação e quiz
- Git e GitHub — versionamento do projeto

## Funcionalidades

- Navegação por 20 assuntos de Eletroeletrônica
- Menu lateral organizado por categorias
- Pesquisa de assuntos em JavaScript
- Carregamento de páginas individuais dos grupos
- Página educacional sobre relés
- Quiz interativo com pontuação
- Layout adaptado para diferentes telas

## Como executar

1. Baixe ou clone o repositório.
2. Extraia os arquivos, caso estejam compactados.
3. Abra a pasta `src`.
4. Dê dois cliques no arquivo `index.html`.
5. Utilize o menu lateral para acessar os assuntos.

A navegação básica e o quiz foram desenvolvidos
para funcionar localmente, sem Live Server.

Mantenha todos os arquivos e pastas na estrutura
original para evitar problemas de carregamento.

## Nosso conteúdo

O assunto 5.4 aborda:

- Conceito de relés eletromecânicos
- Funcionamento da bobina e da armadura
- Contatos normalmente abertos e fechados
- Chaves eletromecânicas
- Exemplos de aplicação
- Recursos visuais
- Resumo para o caderno
- Quiz de aprendizagem

## Integração com outros grupos

O portal utiliza arquivos HTML individuais,
seguindo o padrão de nomenclatura:

- grupo-01.html
- grupo-02.html
- grupo-03.html
- grupo-04.html
- ...

Cada grupo é responsável por desenvolver
seu conteúdo e disponibilizar os arquivos
necessários para integração.
